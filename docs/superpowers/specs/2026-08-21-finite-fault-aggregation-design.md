# Finite Fault Aggregation Design

## Goal

Lift pairwise recovery `joinRecovery` into a theorem about any finite collection of faults: the selected recovery must be independent of arrival order, insensitive to duplicate faults, sufficient for every fault in the collection, and the least recovery action with that property.

## Scope

This is a compact algebraic proof layer. It does not model Browser/Page/Frame state and does not replace `FaultSupervisor`. The supervisor remains executable evidence for generation-tagged adversarial traces; this layer proves the order-independent recovery result abstractly for finite fault collections.

## Aggregate

For a finite list of faults:

```text
aggregateRecovery [] = retry
aggregateRecovery (f :: fs) =
  joinRecovery (minimumRecovery f) (aggregateRecovery fs)
```

`retry` is the least recovery rank and therefore the identity for an empty requirement set.

## Finite permutation relation

Define a small self-contained `FaultPermutation` relation generated by:

- empty permutation
- preserving a common head
- swapping adjacent faults
- transitivity

This avoids introducing a dependency on a larger theorem library while still expressing arbitrary finite reordering.

## Required properties

1. **Permutation invariance**

```text
FaultPermutation xs ys
→ aggregateRecovery xs = aggregateRecovery ys
```

2. **Duplicate invariance**

```text
aggregateRecovery (f :: f :: fs)
=
aggregateRecovery (f :: fs)
```

3. **Combined sufficiency**

Define `CoversFaults faults action` recursively. `aggregateRecovery faults` must cover every fault requirement.

4. **Least combined recovery**

If `candidate` covers every fault in `faults`, then:

```text
recoveryRank (aggregateRecovery faults)
≤ recoveryRank candidate
```

Therefore the aggregate is the least upper bound of all per-fault minimum recoveries.

5. **Unified top-level contract**

```text
MinimalCombined faults (aggregateRecovery faults)
```

where `MinimalCombined` means both coverage and leastness.

## Consequence

For any finite set of current-generation recoverable faults, arrival order and duplicate delivery cannot change the final required recovery. The result is exactly the minimum recovery action sufficient for all observed faults. Generation filtering, unknown/fatal fail-safe handling, and bounded execution remain responsibilities of the existing adversarial supervisor and recovery contracts.
