## What is and is not identified

The previous M5g.1 source experiment shows that two authentic
audit training histories can yield Bob→Alice trust **0.6 vs 0.3**,
yet Bob's target approved belief is **0.5 in both arms immediately
before a later real new source-owned target TELL**. The original
direct-TELL admission produces 0.65 vs 0.5585365853658536 and
both actual native V19 actions remain successful TELL.

This verifies a source mechanism but leaves historical private
memory, social claims and prior source provenance unmatched.
A different action or posterior therefore cannot be attributed
solely to trust for people in the real world.

M5g.2 instead tests a *narrow deterministic software question*:
does the ORIGINAL native direct-TELL trust weighting feature itself
change admitted posterior and downstream native decision values,
when the same genuine original V19 historical Story and target
TELL are evaluated under two explicitly versioned social policies?

This is a two-factor original-V19 **protocol ablation**, NOT a
randomized/empirical trust-only causal trial. The two policy
versions have DIFFERENT hashes; no policy switch can rewrite
an already observed historical record.

## Complete declared 2×2 design (all four cells, no cherry-picking)

| Prior audit Story | Direct TELL weighting ON | Direct TELL weighting OFF |
| --- | --- | --- |
| Confirmed Alice audit TELL and Bob private verification | Learned Bob→Alice trust 0.6; direct effective TELL weight 0.6 | Learned trust 0.6 still source-owned; direct effective weight 1.0 |
| Contradicted Alice audit TELL and Bob private verification | Learned Bob→Alice trust 0.3; direct effective TELL weight 0.3 | Learned trust 0.3 still source-owned; direct effective weight 1.0 |

Every cell executes the SAME original V19/SQLite
\`simulate_situated_percept_social_cognitive_round\` three
times using one native SQLite session per cell:

- Round 7: exact native seven-round audit Story checkpoint;
- Round 8: authentic source-only learning after Bob's own
  inspection, with target approved prior/posterior 0.5;
- Round 9: original native Alice planner emits a source-linked
  NEW target-topic TELL. Bob must receive EXACT;
- Round 10: original native Bob cognition admits that exact
  TELL and executes the MAP selected original world action
  from at least **two real feasible options**, TELL and WAIT.

The ON source policy is the explicit
\`SituatedSocialMemoryPolicy.trust_weight_direct_testimony=True\`
and MUST reproduce parent #130's reviewed M5g.1 source report
exactly, including all original source bytes.

The OFF source policy is the existing default **False**,
and the original source social owner MUST still learn Bob's
actual directed trust from source TELL+INSPECT. OFF changes
**only the direct external TELL likelihood weighting**, not
whether TELL happened, Bob's private perception, remembered
evidence learning, claimed source trust, or world eligibility.
A newly received EXACT target TELL under OFF has effective
direct weight 1.0 (original legacy semantics), regardless of
Bob's legitimate social trust 0.6 or 0.3.

No new planner, source-claim/graph state, fake trust setter
or fabricated event is permitted. Both protocol variants
share the exact world, perception, cognitive model, actions,
rewards, likelihoods, beta, initial physical state, and
historical source Story within each audit-history arm. Only
the social policy and its bound content hashes differ.

## What is still UNPROVEN

The ON/OFF comparison is a controlled *model protocol
counterfactual*: different V19 source social policy versions
produce different direct TELL weights. It can support an
implementation-mechanism statement about weighting, not a
real-world statement that an influential leader caused an
individual's action.

Furthermore, confirmed vs contradicted audit histories have
distinct private memory contents/claims. The cross-history
contrast is not a trust-only treatment. The full design
must retain:

- grid_design = COMPLETE_TWO_FACTOR_NATIVE_PROTOCOL_ABLATION
- native_protocol_mechanism_scope = FINITE_SOFTWARE_POLICY_ABLATION
- source_private_history_match = NOT_MATCHED
- trust_only_causal_effect = NOT_IDENTIFIED
- sample_size_per_arm = 1
- confidence_interval = NOT_ESTIMABLE
- external_validation = NO_EXTERNAL_VALIDATION
- cross_mechanism_ranking = FORBIDDEN

Independent population observations, matched cognitive
histories, source-eligible longitudinal treatment
assignment, confounder controls, predeclared outcomes and
statistical uncertainty remain separate future work.
