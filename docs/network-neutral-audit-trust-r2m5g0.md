# R2.M5g.0 — Neutral training evidence separates source trust from target belief

Tracks Issue #120. Parent is M5f Draft #128, with exact source grid and
inherited Python/Lean/Studio acceptance required before pushing this
experimental branch. M5g.0 is NOT the matched behavioral causal test:
it is a narrower **source-model prerequisite**.

## Why the previous training confounded trust and target cognition

M5e.1 through M5f contrasted prior Alice testimony about whether
restructuring was approved or denied. Bob's own private INSPECT
verified approval and produced an original V19 trust difference
(confirmed 0.6 vs contradicted 0.3). But the training messages and
INSPECT also updated Bob's *approved/denied* target belief.
Equal physical positions alone could not isolate current trust.

This phase uses a distinct **source-audit** social topic, independent
of the target restructuring claim, while preserving the same original
V19 cognitive/social/SQLite owner. Neither Agent mind/trust nor an
observed event is synthesized.

## One new, fully declared source model

Start from original V19 world and native perception (Alice at records,
Bob at open, Carol at lobby, Dana at manager). Declare one new V19
cognitive model shared by both experimental histories, and a social
model that binds exactly this cognition.

There are two distinct source-social topics:
- audit topic source-audit: audit-verified and audit-denied symbols;
- target topic restructuring: approved and denied symbols.

Every Agent cognitive observation model registers both audit symbols,
and original likelihood tables are extended by the **same** fixed
transformation for every action/hypothesis row:

    P_new(approved or denied | action,hypothesis)
        = 0.8 * P_original
    P_new(audit-verified | action,hypothesis) = 0.1
    P_new(audit-denied | action,hypothesis) = 0.1

Rows still sum to 1. Both audit likelihoods are **identical under
approved vs denied**, so an audit symbol has Bayes likelihood ratio 1
and cannot change the target posterior. The target approved/denied
likelihood ratio is unchanged by common 0.8 scaling and remains
informative for later exact target evidence.

Bob's own original INSPECT of memo (actual source fact approved)
is mapped to audit-verified. Alice's original INSPECT remains
a target informative observation; Bob's two distinct prior
audit-message rules use the audit symbols. The social-memory
audit topic, separate from restructuring, is the ONLY topic
eligible for the historic Bob claim and own private verification.
No cross-topic social claim should be generated.
