Tracker: [Issue #120](https://github.com/qigao/lean/issues/120). Stacked

## Theory and measurement purpose

This phase reuses established **task-specific key-player** methods (e.g.
Borgatti 2006). The most useful actor for reaching others can differ
from the actor whose removal interrupts others' connectivity. Neither
is automatically a passage controller, institutionally powerful, credible,
or a verified source of truth. No general social law is being rediscovered.

Model-local candidate measures must explicitly register **graph relation,
direction, roster, time, and objective**. A static path on direct-interaction
opportunities is not a message delivery. A latest-round TELL transmission
cannot be composed into a fictitious temporally ordered multi-hop history.

## Source-owned finite fixture

Create the actual V19 world/perception/cognition/social model, including
an Alice-controlled passage records-open. The fixed initial places are
Alice=records, Bob=open, Carol=lobby, Dana=manager. Two new *native V19
perception-model* directed INTERACTION edges are declared:

- Carol (lobby) -> Bob (open)
- Bob (open) -> Dana (manager)

No edge is inserted by the M5b observer. The unmodified
project_situated_network_snapshot and source_relation_edges select the
DIRECT_INTERACTION view, while MeshSnapshot with one universal Society
verifies it contains exactly the already sourced edges. The existing
find_mesh_path/mesh_path_is_valid check every bounded directed witness.

A read-only, bounded query computes per-Agent in/out degree, source-reachable
endpoints, and deletion sensitivity: number of **previously reachable ordered
pairs among the remaining Agents** that become unreachable in the selected
static graph if this Agent is excluded. The exclusion changes no V19
world, graph owner or historical event. Denominator:
(n-1)*(n-2) eligible ordered pairs after excluding one Agent.

Expected source-scoped interpretation:

- Carol (designer) can reach Bob and Dana via source-backed directed paths,
  so she is the unique *out-reach* leader in this one task.
- Bob (engineer) is the unique *intermediary* whose query-only exclusion
  interrupts Carol->Dana, losing one previously reachable ordered pair.
- Alice (analyst) is the **resource controller** of records-open but is
  disconnected from this source-selected direct-interaction graph.
- Dana (manager) is neither a passage controller nor an intermediary
  merely because of the role label.

There are no actual TELL events or realized transmissions in this source
revision. To avoid transferring graph semantics between categories,
relationship edges are tested separately; the structural reach API
explicitly rejects TRANSMISSION as a multi-hop time-series graph.

## Evidence and security

All output is bound to V19 network/world/story/cognitive/social source hashes,
V24 mesh projection hash, exact Agent roster/roles, graph relation, round
and controller-policy source. It contains no TELL message body or private
perception text. Immutable source-scoped results recompute each finite
metric and path witness, rejecting forged nodes/edges, degree, removal
loss, candidate rankings, private content and causal claims.

No normalization or numeric ranking *across mechanisms*: out-reach and
disruption use separate task definitions. Within a single graph a
task-specific maximum may be reported with ties preserved. These are
descriptive topological properties, NOT predicted diffusion, verified
persuasion, authority, trust, historical actor authentication or a
population causal estimate.
