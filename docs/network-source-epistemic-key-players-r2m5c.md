# R2.M5c — Source-owned epistemic influence, separate from power and topology

Track [Issue #120](https://github.com/qigao/lean/issues/120); stack on
[Draft #122](https://github.com/qigao/lean/pull/122) and its upstream
M5a passage-control work. We are operationalizing well-established
mechanisms rather than trying to prove a universal "powerful people
always decide outcomes" law or re-prove six hops.

## Mechanisms are not aliases

| Dimension | Source owner | What is actually measured |
| --- | --- | --- |
| World resource control | V19 PassageSpec / resolve_situated_round | Exact controller IDs; authorized OPEN succeeds, WAIT leaves passage closed |
| Structural diffusion/disruption opportunity | V19 perception source → V24 selected DIRECT_INTERACTION view | Carol maximum out-reach; Bob maximum query-only removal-loss; zero real TELL events at origin |
| Private perception | V19 source Story / perceptual_timeline | Bob DETECTED versus EXACT TELL fidelity |
| Admission and verification | V19 _social_evidence + original SQLite-backed cognitive/social round | Recalled exact testimony, Bob's OWN private INSPECT evidence, active vs contradicted claim |
| Directed trust / relationship | V19 advance_situated_social_memory → V24 RELATIONSHIP | Bob's trust of Alice; derived Alice→Bob source relationship, reverse direction unaffected |
| Belief response threshold | V19 tracked belief and network metric | Descriptive threshold classification ONLY; no unobserved enacted behavior |

## One original source model, one changed first-stage input

The *single* immutable V19 world has Alice at records, Bob at open,
Carol at lobby and Dana at manager. Alice alone controls records-open.
The original perception model includes directed Carol→Bob→Dana
INTERACTION opportunities, but no actual TELL. Every branch shares the
same world, cognition model, memory policies, claim topics, initial
social trust and original Story identity.

Both arms run six original V19 Story rounds, not a hand-edited graph:

1. Alice INSPECT memo in records: source event later cited by TELL
2. **Only changed input:** Alice WAIT (control) or authorized OPEN_PASSAGE
3. Alice MOVE records→open (identical intent)
4. Alice TELL "The restructuring is denied" with exact prior inspection
   event ID as source (identical intent, NOT a true claim)
5. Bob MOVE open→records (identical intent)
6. Bob privately INSPECT memo reporting approval (identical intent)

The source-world permission drives the movement opportunity and Bob's
TELL fidelity. The **original** V19 SQLite-backed private-memory
cognitive round, source-only social evidence admission, claim
consolidation and verification then run without an alternate engine.

Expected native acceptance:
- WAIT: move fails, Bob only DETECTS TELL and has no admitted testimony
  or claim; his private INSPECT is still legitimate VERIFICATION but
  does not change directed trust without an earlier claim.
- OPEN: move succeeds, Bob receives EXACT TELL and admits one
  unverified testimony. The later private INSPECT contradicts the claim,
  so V19 trust **Bob observing Alice** goes 0.5→0.3. The source-backed
  **Alice→Bob** RELATIONSHIP retires at the registered 0.5 threshold;
  **Bob→Alice** remains.
- Role, passage permission, graph out-reach, claim credibility, belief
  threshold and realized world actions stay different concepts. Bob's
  own cognitive belief before/after and whether it meets the 0.7
  tracked-hypothesis threshold are observations, not proof of a
  post-trust behavioral choice. No action is inferred from the score.

The original one-round social cognition API can process a complete,
six-round source Story as in existing M3 source cases, using a separate
SQLite memory path for each branch. This is NOT six independent social
learning rounds or an identified population causal estimator.

## Source and privacy qualification

The immutable redacted report binds exact V19 world/network/memory/
social/perception model hashes, common initial Story and controlled
passage, native TELL and private INSPECT event hashes, source cognitive
and social snapshots before/after, admitted evidence counts, actual
claim status and directional trust. The native M5b structural source
hash and separate task candidates are included **without** transferring
their meanings to truth or authority.

A repeated event ID on two counterfactual branches must be qualified
by distinct Story hashes; it is not one historical event. The report
may never publish a message, private inspection content, claim symbol,
universal influence score, synthetic trust change or claim of proven
post-trust action. Strict report field allowlists and negative mutations
enforce those limits.

One first-run source corpus is emitted once for review and then pinned
byte-for-byte. Only original \`proof.yml\` V24 Python and independent
Lean source-conformance gates are expanded. Keep full Python, Lean trust,
BB/PathN, Studio/Playwright, ccache/runner bounded singleflight and
upstream PR Draft status; no additional workflow/consumer/installer.

Scope remains a single deterministic, finite controlled source-model
experiment: sample_size_per_arm=1; confidence_interval=NOT_ESTIMABLE;
causal_attribution=UNATTRIBUTED; external_validation=NO_EXTERNAL_VALIDATION.

The subsequent empirical study still needs independent samples,
registered comparisons, explicit outcome/counterfactual definitions,
external source data and assumption-based causal inference. None of
those are supplied by this finite native replay.
