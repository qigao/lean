# R2.M5g.1 — Original V19 neutral audit then NEW target-topic TELL/decision

Parent: [Draft #129](https://github.com/qigao/lean/pull/129) M5g.0,
whose original native source experiment established Bob's directional
trust can learn 0.6 vs 0.3 without changing target approved belief
(0.5/0.5) at the end of audit training. Track Issue #120.

## Question and strict meaning

Can the SAME original V19/SQLite cognitive/social engine:
1. Learn trust solely from an independent source-audit topic;
2. Emit a new ORIGINAL native Alice TELL about the restructuring target
   AFTER that learning;
3. Admit its EXACT private percept using the learned Bob→Alice trust;
4. Execute a native Bob decision with >=2 actually feasible actions?

The experiment is NOT a trust-only causal inference. While both
branches have target prior/posterior 0.5 at the training checkpoint,
their private historical claims, memories and source event IDs differ.
A native target TELL that occurs in an intervening round may change
Bob's target belief before the designated later target TELL. The
report must distinguish these times rather than falsely asserting
complete cognitive-state matching.

## One versioned V19 source model and one owner

Reuse the entire M5g.0 ORIGINAL world, perception, cognitive observation
rules, target-neutral audit symbol likelihoods and social policy.
Register one NEW shared native cognitive-model version, modifying
ONLY the repeatable flag of Alice's and Bob's EXISTING, source-constrained
TELL actions to True. Keep rewards, likelihoods, transitions, goals,
discount, beta, action scheduling, scene permissions and all other
native actions unchanged. The resulting cognitive, memory and bound
social-model hashes are new; the social policy remains identical
in both arms.

No second planner, graph, trust state, Bayesian updater or fallback
is permitted. Alice's new target TELL is emitted and sourced by the
original V19 Agent action planner, not inserted as an authored event.

Historical audit sources are EXACTLY the same seven source-world
actions as the parent M5g.0, with only the previous audit TELL content
confirmed/disputed. The initial seven-round authored Story must retain
the parent's exact Story content hash. Both branches share the same
world, physical locations and declared cognitive/social model.

## Strict original native timeline

- Round 7: source Story checkpoint after the real previous audit TELL
  and Bob's own private INSPECT of the memo.
- Round 8: original SQLite/private-memory social cognitive round must
  admit ONE audit testimony and independent audit verification, learn
  Bob→Alice trust 0.6 confirmed vs 0.3 contradicted, while original
  target approved belief remains exactly 0.5 before and after learning.
- Round 9: the original Alice planner must produce an actual NEW
  target-topic TELL. Its message must agree with her source-declared
  existing TELL action, its causal reference must be an actual
  previously observed eligible native source event, and Bob must
  receive a real source-hash-qualified EXACT percept at his location.
  The two branch Stories remain source-qualified; a shared event ID
  without Story hash is never enough.
- Round 10: the original Bob direct percept/social-memory cognition
  must admit that specific new target TELL with current learned
  Bob→Alice trust, select its actual original Agent action from at
  least TWO feasible actions, and emit the V19 world event with real
  success/outcome. Source rewards/likelihoods and beta cannot be
  adjusted after seeing the action or belief results.

## Confounder ledger is part of acceptance

Record at least these SOURCE observations in every arm:
- training and pre-new-target Bob approved belief;
- native direct TELL prior/posterior; current directional trust;
- M5g.0 original source-history hash; new native target event hash;
- Bob processed observation IDs (redacted as content hash), prior
  selected action IDs (hash), recalled-memory count and private
  observation floor, active audit and target claims;
- full native feasible action roster, original action values,
  softmax policy, MAP decision hash, world outcome and success.

The report must label:
- training_target_belief_match = EXACT_AT_CHECKPOINT_0_5
- pre_new_target_belief_match = EXACT OR
  NOT_MATCHED_AFTER_NATIVE_INTERMEDIATE_EVENTS, based on source data;
- source_private_history_match = NOT_MATCHED
- actual_action_comparison = SAME_MAP OR DIFFERENT_MAP
- trust_only_causal_effect = NOT_IDENTIFIED
- sample_size_per_arm = 1
- confidence_interval = NOT_ESTIMABLE
- external_validation = NO_EXTERNAL_VALIDATION
- cross_mechanism_ranking = FORBIDDEN

Even if the later MAP choices differ, other historical memory/claims
and intermediate events remain possible confounders. This is a
finite native source mechanism, not a universal real-world power
law or isolated population trust effect.
